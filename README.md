# 🚗 CarBookProje — Car Rental Web Application

**CarBookProje** is a full-featured, layered architecture car rental web application developed using ASP.NET Core. It allows users to view available vehicles, make rental reservations, manage bookings, and administer cars, brands, and categories through a structured back-office system.

---

## 🎯 Project Purpose

This project aims to simulate a real-world car rental management system where:

- Users can browse and reserve vehicles
- Admins can manage cars, categories, brands, and reservations
- Developers can learn how to structure a scalable ASP.NET Core application using layered architecture and Entity Framework

---

## 🚀 Main Features

| Feature                      | Description                                                   |
|------------------------------|---------------------------------------------------------------|
| 🚘 Car Listing               | Browse all available cars with filtering and search           |
| 📅 Booking System            | Users can select date range and make reservations             |
| 🏷️ Brand & Category Support | Vehicles can be grouped by brand and category                 |
| 🔒 Admin Panel               | Admin can manage cars, brands, categories, and bookings       |
| 💼 User Management (Planned) | Register/Login and user-specific booking history              |
| 📸 Car Images (Optional)     | Upload feature for vehicle photos                             |
